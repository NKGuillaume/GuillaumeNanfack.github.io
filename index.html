Meaning Ladder

Daily word game · JavaScript, Python, GitHub Actions, OpenAI API, GitHub Pages

Play it (opens Meaning Ladder)

Climb from a start word to a goal word through related meanings. 10+ players, three difficulty levels a day, an archive, and offline play through a service worker.

  • Scheduled GitHub Actions generate the puzzles. An LLM picks each one from a shortlist already verified by BFS shortest paths over the word graph, so no unverified AI output reaches players.
  • Weekday difficulty tuned from graph metrics (par length, route counts). Hints use reverse Dijkstra along natural routes.
  • 210+ automated tests (pytest, Node) in CI. A parse check on every browser script was added after a production outage.

Application Tracker

Full-stack · Python, FastAPI, React, TypeScript, Supabase (PostgreSQL)

Open it (opens Application Tracker)

Reads Gmail through OAuth and uses OpenAI structured outputs to extract the company, role, status, and interview type. It tracked 70+ applications from a live internship search.

  • A two-stage keyword pre-filter kept 97.9% of emails (2,381 of 2,432) away from the LLM, which cut API cost and screened out job-alert spam.
  • Sync time cut 15× (170 s → 11 s) by batching Gmail requests and running LLM calls in parallel with retries.
